# 🎬 Demo Guide - Dynamic Business Insights

## Quick Demo Setup

### Prerequisites

1. Backend API running at `http://localhost:8000`
2. Frontend running at `http://localhost:3000`
3. At least one business created in the database

## Demo Scenario 1: Show Dynamic Prompts

### Step 1: Create First Business

```bash
curl -X POST http://localhost:8000/businesses/ \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tech Startup Inc",
    "industry": "Technology",
    "market": "SaaS"
  }'
```

**Response:**

```json
{
  "id": "tech-startup-001",
  "name": "Tech Startup Inc",
  "industry": "Technology",
  "market": "SaaS",
  "created_at": "2025-11-09T10:00:00Z"
}
```

### Step 2: Upload Transaction Data

```bash
curl -X POST http://localhost:8000/etl/trigger \
  -H "Content-Type: application/json" \
  -d '{
    "business_id": "tech-startup-001",
    "file_url": "https://example.com/tech-startup-transactions.csv",
    "generate_prompts": true
  }'
```

### Step 3: View in Browser

```
http://localhost:3000/?businessId=tech-startup-001
```

**You'll see:**

- ✅ Opt-in screen with "Tech Startup Inc"
- ✅ Industry: Technology • SaaS
- ✅ Click "Enable AI Insights"
- ✅ Dashboard with AI-generated prompts specific to tech startup data

## Demo Scenario 2: Compare Different Businesses

### Create Second Business

```bash
curl -X POST http://localhost:8000/businesses/ \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Retail Shop Ltd",
    "industry": "Retail",
    "market": "E-commerce"
  }'
```

**Response:** `id: "retail-shop-002"`

### Upload Different Data

```bash
curl -X POST http://localhost:8000/etl/trigger \
  -H "Content-Type: application/json" \
  -d '{
    "business_id": "retail-shop-002",
    "file_url": "https://example.com/retail-transactions.csv",
    "generate_prompts": true
  }'
```

### Compare Side by Side

**Open two browser tabs:**

**Tab 1: Tech Startup**

```
http://localhost:3000/business/tech-startup-001
```

**Tab 2: Retail Shop**

```
http://localhost:3000/business/retail-shop-002
```

**Observe:**

- ✅ Different business names in header
- ✅ Different AI-generated prompts (based on their data)
- ✅ Different insights when clicking prompts
- ✅ Same URL structure, different business IDs

## Demo Scenario 4: Quick Switch Demo

### Prepare URLs

```bash
# Business A
http://localhost:3000/?businessId=tech-startup-001

# Business B
http://localhost:3000/?businessId=retail-shop-002

# Business C (if exists)
http://localhost:3000/?businessId=demo-business
```

### Live Demo Script

1. **Show Business A opt-in**

   - "Here's Tech Startup Inc, a SaaS company"
   - Click "Enable AI Insights"
   - Show 6 prompts specific to their data

2. **Change URL to Business B**

   - "Now let's look at Retail Shop Ltd"
   - Different company name, different industry
   - Completely different prompts

3. **Click similar prompt in both**

   - "Notice the same prompt title..."
   - "But completely different insights!"
   - Show follow-up prompts are also different

4. **Execute custom query in both**
   - Type: "What were my top expenses last month?"
   - Show different answers for each business
   - Prove data is truly business-specific

## Demo Talking Points

### 1. URL-Based Architecture

> "Notice how we can switch between businesses just by changing the URL parameter. This makes it incredibly easy to demo multiple clients or test different scenarios."

### 2. Dynamic Prompt Generation

> "These prompts aren't hardcoded. They're generated by AI based on the actual transaction data for each business. That's why Tech Startup sees different prompts than Retail Shop."

### 3. Contextual Insights

> "When we ask 'What are my top expenses?', the system doesn't give generic advice. It analyzes this specific business's transaction data and provides insights tailored to their industry and situation."

### 4. Bank Offering Recommendations

> "Based on the analysis, the system intelligently recommends relevant Nedbank products. A cash flow issue might suggest working capital finance, while growth signals might suggest expansion loans."

### 5. Easy Integration

> "From a technical standpoint, every API call includes the business ID. Whether it's fetching prompts, executing queries, or getting recommendations - everything is scoped to the specific business in the URL."

## Quick Reset for Demo

If you need to reset and start fresh:

```bash
# 1. Clear a business's prompts
curl -X DELETE http://localhost:8000/prompts/{business_id}

# 2. Delete a business completely
curl -X DELETE http://localhost:8000/businesses/{business_id}

# 3. Create new business and start over
curl -X POST http://localhost:8000/businesses/ -H "Content-Type: application/json" -d '{"name": "..."}'
```
